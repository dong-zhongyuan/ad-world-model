# Data sources, versions and outcome definitions

[Source-file checksums](../data/reference/input_checksums.csv) identify the archived input files by accession, deposited filename, byte count and SHA-256. [Processed-matrix checksums](../configs/data_manifest.json) identify the training snapshot used by the model. The [sample manifest](../data/processed/sample_manifest.csv) gives sample, disease, assay, cell type, data split and post-QC counts. GEO accessions identify study series; hashes distinguish the specific files used.

| Source | Role and annotation |
| --- | --- |
| [GSE181279](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE181279) | Human blood. The dataset supplies donor and disease status. The release includes the [Leiden labels](../data/reference/human_blood_labels.csv.gz) and their [annotation code](../scripts/data/reference_builders/relabel_blood_leiden.py). |
| [GSE138852](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE138852), [GSE157827](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE157827) | Human brain. The first series supplies expression and published cell covariates. The 21-donor second series supplies observed cortical expression and the [locked donor partitions](../data/reference/fixed_brain_splits.json). GSE157827 cell types use the marker scores in the [preprocessing code](../scripts/data/prepare_raw_intermediates.py). |
| [GSE329430](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE329430) | Mouse BM1/2, BM3/4 and Brain1. Genotypes, multiplex assignments, marker labels and markers for the expanded Brain1 cells enter the [reference preparation](../scripts/data/build_reference_atlases.py). |
| [GSE164378](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE164378) | Paired human PBMC RNA and antibody-derived tag measurements. Deposited donor and cell-type metadata are joined by barcode. P1–P4 train, P5 validates and P6–P8 test. Log1p antibody counts are centered within cell. |
| [GSE314342](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE314342), [GSE327644](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE327644) | Measured primary CD4 and myeloid perturbations. Guide metadata, perturbation effects and the [action-processing programs](../scripts/real_action) define the input actions. |
| [GSE245309](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE245309) | Brain-isolated phagocytes and microglia. Saline-referenced microglial changes are the observed test outcome. The [benchmark protocol](prediction_benchmark.md) specifies sample IDs, processing, cell annotation, normalization and scoring. |
| [GSE272377](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE272377), [Bin1 conditional knockout, version 1](https://doi.org/10.17632/whgkcy72yv.1) | Independent Grn and Bin1 brain responses. [GRN](../scripts/dynamic_response/evaluate_grn_brain.py) and [BIN1](../scripts/dynamic_response/evaluate_bin1_route.py) process the corresponding count and annotation files. |
| [UKB plasma protein instruments](https://doi.org/10.1038/s41586-023-06592-6), [AGES–Reykjavik serum instruments](https://doi.org/10.1038/s41467-021-27850-z) | The UKB source is worksheets ST3, ST9 and ST14 of the `MOESM3_ESM.xlsx` workbook. The checksum inventory includes the workbook and the assay-specific AGES GWAS accessions. The [MR protocol](../configs/public_followup_protocol.json) records instrument selection, allele alignment and genetic evidence definitions. |
| [Bellenguez stage I, GCST90027158](https://www.ebi.ac.uk/gwas/studies/GCST90027158), [FinnGen R13 G6_ALZHEIMER](https://storage.googleapis.com/finngen-public-data-r13/summary_stats/finngen_R13_G6_ALZHEIMER.gz) | GRCh38 AD outcome summary statistics. [LD-component representatives](../figure_work/data/gene_scores_LD_component_representatives_Bellenguez_stageI.csv) include protein-assay identifiers, alleles, estimates and both candidate lists. |
| [ChEMBL](https://www.ebi.ac.uk/chembl/), [UniProt](https://www.uniprot.org/), [AlphaFold DB](https://alphafold.ebi.ac.uk/) | [ChEMBL 37](../data/reference/chembl_release.json), the [source snapshot](../data/reference/chembl_snapshot.json), [screened structures](../data/reference/screened_parents.tsv), [UniProt entry/sequence versions and AlphaFold model hashes](../data/reference/structural_sources.csv) and [323 pocket records](../data/reference/pocket_sources.csv) identify the structural inputs. The [screen summary](../figure_work/data/drugclip_screening_summary.json) identifies the exact score matrix by SHA-256. The [target tables](../figure_work/data/drugclip_target_summary.tsv) and ten complete parent rankings preserve the 2,297 assayed parent compounds per target, including ChEMBL and UniProt IDs and the selected chemical states. |
| [Enrichr GO Biological Process 2023](../data/reference/GO_Biological_Process_2023.gmt) | The exact gene-set library used for the response-enrichment calculation is included in the checkout. |
